# 🔍 Shakra Search: Quantum-Powered Tech Discovery Engine

An ultra-modern, interactive search portal designed as part of the **ShakraTech** ecosystem. It features smart query routing to seamlessly direct users across personal web applications, cybersecurity tools, and developer profiles.

[![Live Demo](https://img.shields.io/badge/Live-Demo-00ff88?style=for-the-badge&logo=rocket)](https://shakra000.github.io/search-engine/)
[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg?style=for-the-badge)](LICENSE)

---

## ✨ Features & Smart Routing

* **Smart Query Router:** Automatically detects keywords (`universe`, `password`, `github`, `shakra`) and routes visitors to the corresponding live project or profile.
* **Cyberpunk Glassmorphism UI:** Built with sleek dark-mode aesthetics, glowing accents, and responsive input fields.
* **Quick Tags:** Fast-access buttons for immediate navigation across the developer's portfolio.
